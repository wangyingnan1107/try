# 浏览器连接功能使用说明

## 功能说明

当您需要提取需要登录的网页内容时，可以使用"连接已打开的浏览器"功能。这个功能会连接到您当前打开的Chrome浏览器，自动获取您已经登录的状态（Cookie），然后使用这个登录状态来访问网页。

## 使用步骤

### 第一步：以调试模式启动Chrome浏览器

**重要：必须先关闭所有Chrome浏览器窗口！**

然后根据您的操作系统，使用以下命令启动Chrome：

#### Windows系统

1. 按 `Win + R` 打开运行对话框
2. 输入以下命令（根据您的Chrome安装路径调整）：
   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
   ```
   
   或者，如果Chrome安装在默认位置，可以直接在命令行运行：
   ```cmd
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
   ```

**提示：** 为了方便，您可以创建一个快捷方式：
1. 右键桌面 → 新建 → 快捷方式
2. 在"对象位置"中输入：
   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
   ```
3. 命名为"Chrome调试模式"
4. 以后直接双击这个快捷方式即可

#### Mac系统

打开终端（Terminal），运行：
```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222
```

#### Linux系统

打开终端，运行：
```bash
google-chrome --remote-debugging-port=9222
```

或者：
```bash
chromium-browser --remote-debugging-port=9222
```

### 第二步：在Chrome中登录目标网站

Chrome启动后，在浏览器中：
1. 访问需要登录的网站
2. 完成登录操作
3. 确保登录状态正常（可以访问需要登录才能查看的内容）

### 第三步：在程序中连接浏览器

1. 启动程序（如果还没启动）：
   ```bash
   streamlit run main.py
   ```

2. 在程序界面的侧边栏找到"🔗 浏览器连接"区域

3. 勾选"连接已打开的浏览器"复选框

4. 确认调试端口为 `9222`（如果使用其他端口，请修改）

5. 点击"🔌 连接浏览器"按钮

6. 如果连接成功，会显示"✅ 浏览器连接成功！已获取登录状态。"

### 第四步：提取网页文字

1. 在URL输入框中输入要提取的网页地址（可以是需要登录才能访问的页面）

2. 如果连接了浏览器，程序会自动使用Selenium模式（即使没有手动勾选）

3. 点击"🔍 提取文字"按钮

4. 程序会使用您浏览器中的登录状态来访问网页，并提取文字内容

## 注意事项

1. **调试端口**：
   - 默认端口是 `9222`
   - 如果端口被占用，可以修改为其他端口（如 `9223`、`9224` 等）
   - 但需要确保Chrome启动时使用的端口与程序中设置的端口一致

2. **浏览器版本**：
   - 需要Chrome浏览器
   - 其他基于Chromium的浏览器（如Microsoft Edge、Brave等）也支持，但命令可能不同

3. **安全提示**：
   - 调试模式会暴露浏览器控制权
   - 使用完毕后建议关闭调试模式的Chrome窗口
   - 不要在不安全的环境中使用此功能

4. **Cookie时效性**：
   - 如果网站登录状态过期，需要重新登录
   - 重新登录后，可以点击"🔌 连接浏览器"按钮重新获取登录状态

5. **断开连接**：
   - 使用完毕后，可以点击"🔌 断开连接"按钮
   - 或者直接关闭程序

## 常见问题

### Q: 连接失败，提示"无法连接到浏览器"

**A:** 请检查：
1. Chrome是否以调试模式启动（必须使用 `--remote-debugging-port=9222` 参数）
2. 所有Chrome窗口是否都已关闭后重新启动
3. 调试端口是否正确（默认9222）
4. 防火墙是否阻止了连接

### Q: 连接成功但提取文字时提示需要登录

**A:** 可能的原因：
1. Cookie已过期，需要重新登录网站
2. 网站使用了特殊的认证机制
3. 尝试重新连接浏览器（点击"断开连接"后再"连接浏览器"）

### Q: 可以同时连接多个浏览器吗？

**A:** 不可以，一次只能连接一个浏览器实例。如果需要切换，先断开当前连接，再连接新的浏览器。

### Q: 连接浏览器后，Chrome窗口会自动关闭吗？

**A:** 不会。连接浏览器只是获取Cookie，不会关闭Chrome窗口。您可以继续正常使用Chrome浏览器。

### Q: 使用这个功能会影响浏览器正常使用吗？

**A:** 不会。连接后您可以继续正常使用Chrome浏览器。程序只是读取Cookie，不会干扰您的正常浏览。

## 技术说明

- 程序使用Selenium连接到Chrome的远程调试接口
- 自动获取当前页面的所有Cookie
- 将Cookie应用到requests Session中
- 后续请求自动携带Cookie，保持登录状态
- 支持JavaScript跳转检测和等待

## 示例场景

### 场景1：提取需要登录的论坛帖子

1. 以调试模式启动Chrome
2. 在Chrome中登录论坛
3. 在程序中连接浏览器
4. 输入帖子URL，提取文字内容

### 场景2：提取需要登录的文档系统内容

1. 以调试模式启动Chrome
2. 在Chrome中登录文档系统
3. 在程序中连接浏览器
4. 输入文档URL，提取文字内容

### 场景3：提取有跳转的网页

1. 连接浏览器（可选，如果不需要登录可以跳过）
2. 输入URL
3. 程序会自动检测JavaScript跳转并等待页面加载完成
4. 提取最终页面的文字内容
