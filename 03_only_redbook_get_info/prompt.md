## 2. 背景

把“小红书页面采集”能力独立成一个面向 OpenClaw 的 skill，使其能够在用户浏览页面并手工触发采集后，输出一份结构化的小红书笔记信息。

## 4. Why

### 4.1 管理目标

- 将现有项目中的采集能力模块化，便于复用。
- 为 OpenClaw 提供一个独立、清晰、可维护的 skill 能力。
- 将“小红书内容获取”与“后续分析/报告生成”解耦。

### 4.2 业务目标

- 提高用户获取小红书内容的效率。
- 支持快速形成后续分析材料。
- 保持“所见即所得”的使用体验。
- 保证来源二独立后的输出结果可无缝接入现有飞书文档写入链路。
- 在满足结果一致的前提下，尽量降低 token 消耗。

- 如果只拿到时间或只拿到地点，则“有什么写什么”。
